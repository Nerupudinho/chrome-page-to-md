# Privacy Policy

**Page to Markdown** is a browser extension that converts web pages to Markdown files.

## Data Collection

This extension does **not** collect, store, transmit, or share any user data.

## How It Works

When you click the extension icon:

1. The extension reads the content of the currently visible webpage in your browser tab.
2. It extracts the main article content locally using the Readability library.
3. It converts that content to Markdown format locally using the Turndown library.
4. It triggers a download of the resulting `.md` file to your device.

All processing happens entirely on your device. No data is sent to any server.

## Permissions Used

- **activeTab**: Allows the extension to access the content of the tab you click on, only when you click the extension icon.
- **scripting**: Allows the extension to inject the content extraction scripts into the active tab.

## Third-Party Services

This extension does not use any third-party services, analytics, tracking, or advertising.

## Contact

For questions about this privacy policy, please open an issue on the [GitHub repository](https://github.com/Nerupudinho/Page-to-Markdown).
