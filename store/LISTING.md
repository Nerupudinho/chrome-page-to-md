# Chrome Web Store Listing

## Extension Name

Page to Markdown

## Short Summary (≤132 characters)

Save any webpage as a clean Markdown file with one click. Extracts article content and converts it locally—no data sent anywhere.

## Detailed Description

**Page to Markdown** lets you save any webpage as a clean, readable Markdown (.md) file with a single click.

### How It Works

1. Navigate to any webpage you want to save
2. Click the extension icon in your toolbar
3. A Markdown file downloads to your device automatically

### Features

- **One-click conversion** – No menus, no configuration, just click and save
- **Clean extraction** – Uses Mozilla Readability to extract the main article content, removing ads, navigation, and clutter
- **Proper Markdown** – Converts headings, lists, links, images, and code blocks correctly
- **Works offline** – All processing happens locally on your device
- **Privacy-first** – No data is collected, stored, or sent to any server

### Perfect For

- Researchers saving articles for later reading
- Writers collecting reference material
- Students archiving web content for studies
- Anyone who prefers Markdown for note-taking

### Technical Details

Built with:
- Mozilla Readability for content extraction
- Turndown for HTML-to-Markdown conversion
- Chrome Manifest V3 for modern extension architecture
